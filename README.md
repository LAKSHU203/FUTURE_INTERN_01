# 🐾 PawCare - Pet Care Website UI/UX Design

## 📌 Project Overview

PawCare is a high-conversion pet care website UI/UX design created in Figma. The project focuses on delivering a clean, modern, and user-friendly experience while encouraging users to book pet care services.

## 🎯 Objective

Redesign a local pet care service website with a strong focus on user experience, lead generation, and conversion optimization.

## 🛠️ Tools Used

* Figma
* UI/UX Design Principles
* Prototyping

## 📄 Pages Designed

* Home Page
* Services Page
* About Page
* Contact Page

## ✨ Key Features

* Modern and clean interface
* Consistent color palette and typography
* Conversion-focused Call-to-Action (CTA) buttons
* Service showcase section
* Contact and appointment booking form
* Responsive website layout
* Interactive prototype
